# Vánoce bez starostí 🎄

Jednoduchá Next.js aplikace pro službu doručování vánočních stromků až domů.

## 🧩 Spuštění lokálně

```bash
npm install
npm run dev
```

Aplikace poběží na: http://localhost:3000

## 🚀 Nasazení na Vercel
1. Nahraj projekt na GitHub
2. Přihlas se na [https://vercel.com](https://vercel.com)
3. Klikni „New Project“ → vyber repozitář → Deploy
